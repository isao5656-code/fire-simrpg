# 炎翼の紋章（えんよくのもんしょう）

ファミコン時代のシミュレーションRPGを、ブラウザだけで遊べるようにしたターン制タクティクスです。
三すくみ・追撃・必殺・地形効果・成長率・戦死（ロスト）といった、あのジャンルの手触りを一通り実装しています。
全6章、依存ライブラリなし（HTML + CSS + 素のJavaScript）。

## 遊びかた

`index.html` をブラウザで開くだけで動きます。ローカルサーバー経由でも構いません。

```bash
python3 -m http.server 4173   # → http://localhost:4173/
```

### 基本の流れ

1. 自軍フェイズに味方を選ぶ（青＝移動できるマス、赤＝そこから攻撃できるマス）
2. 移動先を選ぶとコマンドが開く（攻撃／杖／訪問／制圧／道具／装備／待機）
3. 攻撃を選ぶと **戦闘予測**（与ダメージ・命中・必殺・反撃）が右側に出る
4. 全員が行動を終えると敵軍フェイズ
5. 章の勝利条件を満たせば次章へ。進行状況はブラウザに自動保存されます

### 操作

| | |
|---|---|
| マウス | クリックで選択・決定／右クリックで取り消し |
| カーソル | ←↑↓→ |
| 決定 / 取り消し | Enter・Z ／ Esc・X |
| 次の未行動ユニット | Tab |
| 危険地帯（敵の攻撃範囲）の表示 | D |
| ターン終了 | T |

## 戦闘のしくみ

- **三すくみ** 剣 > 斧 > 槍 > 剣（命中+15 / 威力+1）。魔法は 炎 > 風 > 雷 > 炎
- **命中率** `技×2 + 幸運÷2 + 武器命中 + 相性` − `攻速×2 + 幸運 + 地形回避`。判定は2回振って平均をとる方式（表示どおりに当たりやすい）
- **攻速** `速さ − (武器の重さ − 力)`。相手より4以上高いと**追撃**（2回攻撃）
- **必殺率** `技÷2 + 武器必殺 − 相手の幸運`。ダメージ3倍
- **ダメージ** `力(魔法なら魔力) + 威力 + 相性 − 守備(魔法なら魔防) − 地形守備`
- **特効** 弓は飛行ユニット（ペガサス・ドラゴン）に威力2倍
- **地形** 森・丘・山は回避と守備が上がる。砦・城門・玉座は毎ターンHPが2割回復
- **移動タイプ** 徒歩／騎馬／重装／飛行で地形コストが変わる。飛行は川や山を無視、重装と騎馬は山や川に入れない
- **経験値** 攻撃・撃破・杖での回復で入手。100で1レベル上がり、キャラごとの成長率で能力が伸びる（上限Lv20）

## 勝利条件と敗北条件

| 種別 | 内容 |
|---|---|
| 敵の全滅 | 敵ユニットをすべて倒す |
| 敵将の撃破 | ボスを倒す |
| 玉座の制圧 | アルドを玉座（♛）に立たせて「制圧」 |
| 生存 | 指定ターン数を耐え抜く |

アルドが倒れるとその章は失敗です。倒れた味方は以降の章に戻りません（「やり直し」で章の最初から再挑戦できます）。

## 章と仲間

| 章 | 舞台 | 勝利条件 | 加入 |
|---|---|---|---|
| I | 辺境の狼煙 | 敵の全滅 | アルド／ミレイユ／ボルス／セラ |
| II | 霧深き古城 | 敵将バルガスの撃破 | ガレス／リンネ |
| III | 竜鱗の渡し | 敵将ケルドの撃破 | ノヴァ |
| IV | 黒鋼の要塞 | 玉座の制圧 | ドルガ |
| V | 白銀の峠 | 8ターンの生存 | シェイド |
| VI | 王都奪還 | 玉座の制圧 | — |

民家（⌂）を訪問したり、特定の敵を倒すと、武器や能力上昇アイテムが手に入ります。
拾った武器は、それを扱える兵種の味方へ自動的に渡されます。

## ファイル構成

```
index.html        画面構造（タイトル／出撃前／戦闘／各種オーバーレイ）
style.css         見た目とアニメーション
src/core.js       名前空間・乱数（シード指定可）
src/data.js       地形・武器・兵種・キャラクター・全6章のマップと配置
src/rules.js      戦闘計算・成長・経験値（副作用のない純粋ロジック）
src/grid.js       マップ・移動範囲（ダイクストラ）・攻撃範囲・経路
src/ai.js         敵の思考（起動判定・攻撃手の評価・接近）
src/audio.js      WebAudioによる8bit風の効果音とBGM
src/game.js       ゲーム進行の状態機械
src/ui.js         DOM描画・演出・入力
src/main.js       起動と画面外ボタンの結線
tests/            単体テスト・自動プレイ・バランス確認
```

## 開発用コマンド

```bash
npm test          # 単体テスト（戦闘計算・移動・成長・章データの妥当性）
npm run sim       # UIなしで全6章を自動プレイし、勝率と所要ターンを集計
npm run balance   # 想定レベルでの自軍と敵の噛み合わせを一覧表示
```

`src/rules.js`・`src/grid.js`・`src/ai.js` はDOMに依存しないため、Node.jsからそのまま読み込めます。
乱数は `src/core.js` の `Rng` にシードを渡せば再現可能です。
